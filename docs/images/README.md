# 演示动图（可选）

README 目前用了一张静态界面截图（托管在 GitHub 的 user-attachments，不占仓库体积）。

如果之后想加**动图**，按下面做，能把"顺滑刷片"这个卖点讲得比文字清楚得多：

## 建议加两段

| 文件名 | 内容 | 规格 |
|---|---|---|
| `scrub.gif` | 触摸板左右推拉，视频顺滑快进/快退、时间码飞转 | 宽 960，5–8 秒，≤ 5MB |
| `markers.gif` | 按 A / B / C / D 打点，右侧标记列表实时新增 | 宽 960，5–8 秒，≤ 5MB |

## 怎么录

推荐 **ScreenToGif**（免费，Windows）：https://www.screentogif.com/

1. 打开 MarkPlay，载入一段 1080p 素材
2. ScreenToGif → 新建录制 → 框选视频区 + 侧栏
3. 帧率 15fps 足够（体积小、看着也顺）
4. 录完裁掉多余首尾帧，导出 GIF
5. 存到本目录，文件名用上表的名字

> 控制在 5MB 以内。超过 10MB 的仓库图片会让访客等很久，反而扣分。

## 挂到 README

在 `README.md` 的「界面」小节里加一行即可：

```markdown
![用触摸板顺滑刷片](docs/images/scrub.gif)
```

提之前先本地预览确认路径正确——**GitHub 只显示仓库内的相对路径图片**，不要用本地绝对路径，也不要用外部图床（国内可能加载不出）。
